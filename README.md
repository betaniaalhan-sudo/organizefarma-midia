# organizefarma-midia

Artes e mídias públicas do Instagram da Organize Farma (@betaniaalhan).

- `ROTINA.md`: a rotina diária de postagem (formatos, temas, regras de variedade, publicação)
- `banco-de-angulos.md`: os ângulos de cada tema, marcados quando usados
- `posts/registro.csv`: tudo o que já foi produzido e publicado
- `fonte/arte.py`: o gerador de artes com a marca (carrossel, card, stories, reel)
- `marca/`: a logo oficial
- `ferramenta/`: a ferramenta de linha de comando do Instagram e o verificador de legendas (sem token)
